# DÉZEL Admin Dashboard

لوحة تحكم إدارة المنتجات والتصنيفات والطلبات والمخزون لمتجر DÉZEL.

## الملفات
- `index.html`: لوحة التحكم.
- `config.js`: إعداد الاتصال بمشروع Supabase نفسه المستخدم للمتجر.
- `supabase.sql`: مخطط قاعدة البيانات.

انشر هذا المستودع على نطاق/مسار محمي مناسب. الرابط العام للوحة هو `/` بعد النشر؛ أضف حماية وصول على مستوى الاستضافة. غيّر بيانات الدخول الافتراضية من تبويب الإعدادات، ولا ترفع مفاتيح Supabase السرية `service_role` إلى GitHub.
